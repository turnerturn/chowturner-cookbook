# Gluten-Free Recipe Collection

**48 unique recipes | All ingredient lists normalized to one serving**

Sources: uploaded README (22 recipes) and saved MyFitnessPal export (27 recipes), with one overlapping recipe consolidated.

## How to use this catalog

- Ingredients are **per one serving**. README quantities use a five-serving baseline (the README states 4-5 servings). MyFitnessPal quantities use their original stated serving counts.
- Measurements are fractions where possible. For packaged goods, quantities like 2/5 of a can represent an exact per-serving scale, not a typical package size.
- When the saved text contains multiple quantities, parenthetical conversion, or ambiguous ingredient groupings, the amount is an approximation. Original ingredient strings are retained in JSON for validation.
- Gluten-free alternatives are used or noted. Check certified GF labels on oats, miso, sauces, soup bases and pasta.
- All preparation steps are **editorial cooking outlines**, not the full original recipe directions; use the linked source for exact timing and process.
- Ratings apply **only to linked comparable published recipes**, not to the saved MyFitnessPal entries.
- Original image links are preserved. Missing photos remain flagged rather than substituted with unrelated images.

## 1. Tom Kha Gai Soup

- 3/5 c GF chicken broth
- 1 3/5 oz mushrooms, sliced
- 2/5 stalks lemongrass, bruised
- 1 1/5 slices galangal

- 2/5 Thai chilies, sliced
- 2/5 Tbsp GF fish sauce
- 3/5 Tbsp lime juice
- 2/5 tsp brown sugar
- 1/5 /4 c cilantro, chopped

### Preparation (editorial adaptation)
